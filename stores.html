This list is also available as an API.

GET https://api.opencryptopay.io/map/places

Optional query parameters: country, shopName (SPAR or others), blockchain, and asset. The response is JSON { "places": [ ... ] }.

Filter values: GET https://api.opencryptopay.io/map/filters
